# Privacy notes

Microphone analysis remains browser-side. The practice studio never uploads or stores raw audio or recordings. The only files that leave the browser are ones a person deliberately attaches to an assignment (see below). Local mode stores versioned derived summaries, routines, rewards, and preferences in browser storage. Optional backend mode stores only user identity, derived summaries, routines, and explicit teacher/student assignments in local SQLite.

Users should clear browser site data and delete backend records through the API/database administrator when required. Development authentication is not production-ready. Use a private deployment, a strong secret, HTTPS, restricted CORS, backups, retention rules, and a reviewed identity provider before collecting data from real users, especially younger users. No production security certification is claimed.
## Phase 5 coaching

AI is optional and disabled by default. The coach receives only verified, derived metrics when an explicitly configured server-side provider is used; raw audio, PCM, browser storage, authentication secrets, and API keys are never sent. Provider failures fall back to deterministic offline coaching and do not block practice. API keys belong only in server environment configuration. Local model downloads and external knowledge sources require separate licensing and user approval. Stored sessions remain audio-free and contain derived summaries only.

The previously exposed key must be considered revoked; create a replacement and place it only in a local ignored environment file. It is not present in this repository, tests, frontend code, localStorage, logs, responses, or documentation.

Assignment files (optional, academy mode only). A teacher can attach audio, video, PDF or image files to an assignment, and a student can attach files, such as a Riyaz recording, to their answer. Files are uploaded straight from the browser to the academy's private Cloudflare R2 bucket; the API stores only the file name, type, size and storage key. Nothing is public: every download uses a link the API signs only after checking access, and the link expires after one hour. A student's answer files can be opened by that student and by the assignment's teacher, only after the student submits; the Owner and other teachers and students cannot open them. Deleting an assignment deletes every file attached to it and to its answers. Uploads that are never confirmed are deleted after a day. Without R2 configured, uploads are off and only links can be attached.
